# JustLearn

A minimalist SwiftUI vocabulary app for learning new words on iOS, iPadOS and macOS.

## Features

- **Word list** — add, edit, sort and organize words with translations and notes.
- **Tags** — group words by custom colored tags and filter your list.
- **Cards mode** — flip through flashcards to review vocabulary.
- **Writing mode** — practice by typing translations and track your progress.
- **Settings** — light/dark theme, alternate app icons, learning direction and notifications.
- **Onboarding** — quick intro with privacy and notification setup on first launch.

## Tech Stack

- SwiftUI
- SwiftData
- Swift Concurrency (`async`/`await`)
- Swift Testing + XCUIAutomation

## Requirements

- Xcode 16+
- iOS 18 / iPadOS 18 / macOS 15 or later

## Getting Started

1. Clone the repository.
2. Open `JustLearn.xcodeproj` in Xcode.
3. Select a simulator or device and run.
